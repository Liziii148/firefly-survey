# firefly 满意度调研报告网站 · 第三十六期对齐修订版

本版本按用户提供的第三十六期报告结构排列，保留原问卷 Excel 导入、浏览器本地存储与报告导出。

## 更新网站

将本目录全部文件上传到已有 `firefly-survey` 仓库根目录并替换同名文件。新增的 `report-schema.js`、`report-alignment.js` 必须一起上传。GitHub Pages 来源保持 `main / (root)`。更新后强制刷新页面。

## 第三十六期报告对照

1. 打开网站并导入原问卷 Excel；旧版已导入的数据会保留，无需重复上传。
2. 点击“导入本地报告校准包”，选择单独交付的 `firefly-period36-reference.json`。
3. 系统验证当前问卷响应指纹。匹配后可以切换“报告原值”和“Excel重新计算”。校准包中的报告原值不是重算结果。
4. 报告原值模式下，“导出报告”打开原 PDF，可下载或打印。
5. “报告核对与设置”提供17个一级维度、106个二级细项的670项均分、比例对照；可下载 CSV。

**校准包包含第三十六期内部报告内容，仅在自己的浏览器导入，不要上传到公开 GitHub 仓库。** 网站代码不含问卷记录或原 PDF。

## 已修改

- 恢复报告结构：整体结论；用户画像下的基本信息、拥车情况、购车决策、进店因素及产品关注点、充电条件；用户满意度下的整体及分维度满意度。
- 基本信息恢复实际使用者性别估算、城市分级模块；城市汇总到市级而非省市区完整字符串。
- 满意度固定原报告17个一级维度及106个二级细项的顺序、映射，不按Excel列顺序自动推断所属维度。
- 普通比例与一级满意率恢复整数百分数；均分两位小数，评分分布一位小数。
- 购买原因原标签表16项、报告展示10类分别保存，撤回混合19类；旧关键词分类不进入正式占比。
- 原声改为人工勾选，每类最多3条，撤回按原文长度自动选取。
- “仅对比1台车”表按报告脚注取对比第1列，不再按前置题筛选；标题与脚注冲突公开列出。
- MINI相关车型按报告合并；拥车占比分母未确认前只显示提及数，不发布假定分母计算的正式占比。
- 历期比较移出正式报告；不根据缺失的历史数据自行生成趋势结论。
- 取消未经确认的默认年龄算法；年龄、城市等级、拥车分母可在确认后设置。

## 核对结果与尚未解决的口径

670项满意度指标中669项一致；能量回收整体题Excel重算4.44，报告4.42。
76项常规画像/多选比例中74项一致；工作地充电与居住地公共充电，Excel为14%/16%，报告为16%/14%。
其他待确认：实际用车人性别估算公式、年龄基准与筛除规则、完整2025城市等级映射、车型清洗及分母、对比第1列报告266而数据265、购买原因逐条历史编码、原报告4.35/4.36及97%/98%冲突、重复车型行。
不能将直接转录的报告值称为程序已复现的统计公式。
